# ★ 2026-08-19 · 순서를 바꿨습니다
#   전에는 여기에 「Allow: /」 가 먼저 있었습니다. 구글은 「더 구체적인 규칙이
#   이긴다」로 읽어 문제가 없지만, 「먼저 나온 규칙이 이긴다」로 읽는 단순한
#   봇에게는 그 한 줄이 <아래 차단을 모두 무력하게> 만듭니다.
#   그래서 막을 것을 먼저 적고, 「그 밖에는 다 좋다」를 맨 끝에 둡니다.
# 관리 화면 — 폴더 단위로 막아 앞으로 도구가 늘어도 저절로 막힙니다
Disallow: /admin/
# 회원 개인 화면
Disallow: /account/
# 글쓰기·수정 화면 (색인될 값이 없습니다)
#   ★ 「/*」 로 시작하는 규칙은 구글·빙·네이버·다음은 알아듣지만, 규칙을
#     단순하게 읽는 낡은 봇은 무시합니다. 그런 봇은 검색 결과를 보여 주는
#     쪽이 아니라 어차피 위 1번에서 막는 대상이므로 그대로 둡니다.
Disallow: /db/write.html
Disallow: /*-write.html
Disallow: /*?edit=
# 검색 결과 화면 (같은 내용이 여러 주소로 잡히는 것을 막습니다)
Disallow: /search.html?
Disallow: /*?q=
Disallow: /*?page=
# ★ 2026-08-07 보탬 — 폴더 규칙이 놓치던 개별 화면
#   /lesson/ 안에 회원·관리자 전용 화면이 섞여 있어 폴더로는 막히지 않습니다.
Disallow: /lesson/my-lessons.html
Disallow: /lesson/instructor-apply.html
Disallow: /lesson/curate.html
# ★ 2026-08-19 보탬 — /brand/ 는 우리끼리 보는 디자인 규칙 문서입니다.
#   어디에서도 링크하지 않으므로 찾아오기 어렵지만, 값싼 보험으로 막아 둡니다.
Disallow: /brand/
Disallow: /brand.html
#   ★ /partials/ 는 <막지 않습니다>. 머리글·꼬리글을 자바스크립트로 여기서
#     받아 오기 때문입니다. robots.txt 로 막으면 구글이 화면을 그릴 때
#     메뉴를 못 받아 <링크를 따라가지 못합니다>(「차단된 리소스」 경고).
#     색인만 막는 것은 vercel.json 의 X-Robots-Tag: noindex 로 합니다.
# ★ 상세 화면 — 내용을 자바스크립트로 불러오므로 봇에게는 빈 껍데기입니다.
#   빈 페이지가 색인되는 것을 막습니다. 나중에 서버에서 미리 그려 주게 되면
#   아래 줄을 지우면 풀립니다.
Disallow: /*-view.html
